## Agent skills

### Issue tracker

Las incidencias se administran como Markdown local bajo `.scratch/`. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Se utilizan las etiquetas estándar `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` y `wontfix`. Ver `docs/agents/triage-labels.md`.

### Domain docs

El repositorio usa contexto único mediante `CONTEXT.md` y decisiones en `docs/adr/`. Ver `docs/agents/domain.md`.
