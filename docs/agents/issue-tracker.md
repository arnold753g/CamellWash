# Seguimiento local

Las incidencias y PRD se guardan como Markdown bajo `.scratch/`.

- Una carpeta por funcionalidad: `.scratch/<funcionalidad>/`
- PRD: `.scratch/<funcionalidad>/PRD.md`
- Incidencias: `.scratch/<funcionalidad>/issues/<NN>-<nombre>.md`
- El estado se registra mediante una línea `Status:`
- Las conversaciones se agregan bajo `## Comments`
