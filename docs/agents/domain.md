# Documentación del dominio

Este repositorio utiliza contexto único.

Antes de trabajar:

- Leer `CONTEXT.md` cuando exista.
- Consultar las decisiones relevantes de `docs/adr/`.
- Utilizar el vocabulario definido por el dominio.
- Señalar explícitamente cualquier contradicción con una decisión arquitectónica.
- Si estos archivos todavía no existen, continuar sin bloquear el trabajo.
